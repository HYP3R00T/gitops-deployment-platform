# Mise Troubleshooting

Use this section to diagnose setup issues, task failures, and performance problems.

## Quick Checks

- Run `mise doctor` for a full health report.
- Run `mise list` to confirm installed tools and versions.
- Run `mise activate` if commands are missing after install.
